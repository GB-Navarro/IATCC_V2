A variation to a KIKO (Non sequential) where the knock in barrier is only live on expiry. An option to buy (sell) the notional amount of the specified asset on the expiry date at the specified strike price with two barriers. The first barrier is a knockout American barrier meaning that if this barrier is hit anytime during the life of the option then it knocks out. This barrier is positioned out-the-money. The second barrier is a knock-in and is European meaning it is only live on expiry and is positioned in-the-money. The user can select if they want the payout to happen if spot is either above or below the European barrier on expiration.
