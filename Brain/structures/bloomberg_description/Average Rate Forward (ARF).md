When settled in the domestic currency, an Average Rate Forward (ARF) is a forward whose payoff is set by the difference between the strike and the average rate of the spot over an averaging period. When settled in the foreign currency, an ARF is a forward whose payoff is set by the difference between the inverse of the average rate of the spot and the inverse strike. The payoff is no longer a linear combination of spots over the averaging period, so volatility is involved when computing this case. If the averaging method is Geometric, volatility is always required.
