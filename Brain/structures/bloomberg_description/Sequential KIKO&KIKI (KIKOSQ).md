KIKO Sequential: This is a knockin option that can knockout only once the knock-in barrier has traded. It is irrelevant if spot trades at the knock-out barrier first, the knock-in barrier must trade first before the option can knock out.

KIKI Sequential: This is a Knock-In option that can be activated by another Knock-In barrier.

For an UpIn&DownIn: If the UpIn barrier is never reached, the option expires worthless.  If the UpIn barrier is reached first, the option becomes a DownIn option.  If thereafter, the DownIn is reached, then the option becomes a vanilla.  It is irrelevant whether or not the DownIn is reached first or not.  The payoff depends only on the UpIn barrier being reached before the DownIn.

For a DownIn&UpIn: If the DownIn barrier is never reached, the option expires worthless.  If the DownIn barrier is reached first, the option becomes an UpIn option.  If thereafter, the UpIn is reached, then the option becomes a vanilla.  It is irrelevant whether or not the UpIn is reached first or not.  The payoff depends only on the DownIn barrier being reached before the UpIn.
